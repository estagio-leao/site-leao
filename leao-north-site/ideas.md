# Ideias de Design — Leão North

## Abordagem 1: Industrial Premium Dark
<response>
<text>
**Design Movement:** Industrial Brutalism com toques de Luxury Engineering

**Core Principles:**
- Contraste extremo entre preto profundo e dourado metálico
- Tipografia bold e assertiva para transmitir poder e confiança
- Geometria angular e linhas diagonais remetendo a circuitos elétricos
- Textura sutil de metal escovado no fundo

**Color Philosophy:**
- Preto profundo (#0A0A0A) como base — transmite sofisticação e poder
- Dourado metálico (#C9A84C → #F0C040) como acento — remete a condutores elétricos e prestígio
- Branco puro (#FFFFFF) para texto e contraste
- Cinza chumbo (#1A1A1A, #2A2A2A) para camadas de profundidade

**Layout Paradigm:**
- Seções assimétricas com cortes diagonais
- Hero com split-screen: texto à esquerda, imagem à direita com borda dourada
- Cards com bordas douradas e hover que ilumina como circuito elétrico

**Signature Elements:**
- Linhas douradas diagonais que percorrem seções como fios elétricos
- Ícones com glow dourado no hover
- Números de estatísticas em dourado bold

**Interaction Philosophy:**
- Hover effects que simulam "energização" — glow dourado se expande
- Scroll reveal com fade-up suave
- Botões com efeito de "faísca" no hover

**Animation:**
- Entrance: fade-up com 60ms stagger entre elementos
- Hover cards: border-color transition 200ms + subtle scale(1.02)
- Botões: scale(0.97) no active, glow pulse no hover

**Typography System:**
- Display: Bebas Neue (bold, impactante)
- Body: Raleway (elegante, legível)
- Accent: Rajdhani (técnico, moderno)
</text>

## Abordagem 2: Corporate Precision Gold
<response>
<text>
**Design Movement:** Neoclassical Corporate com Engineering Precision

**Core Principles:**
- Elegância corporativa com identidade de engenharia de alto padrão
- Hierarquia visual clara com uso estratégico do dourado
- Espaçamento generoso e respiração entre elementos
- Combinação de fundo escuro e seções claras para ritmo visual

**Color Philosophy:**
- Fundo escuro (#0D0D0D, #111111) nas seções hero e destaque
- Dourado (#D4A017, #F5C842) como cor primária de ação e acento
- Branco (#FAFAFA) para seções de conteúdo
- Cinza escuro (#1C1C1C) para cards e elementos secundários

**Layout Paradigm:**
- Navbar com linha dourada inferior
- Hero full-height com imagem de fundo + overlay escuro + texto centralizado
- Seções alternando entre fundo escuro e claro
- Grid de 3 colunas para serviços com cards premium

**Signature Elements:**
- Linha dourada horizontal como separador de seções
- Ícones circulares com borda dourada
- Números em destaque com cor dourada

**Interaction Philosophy:**
- Transições suaves e elegantes
- Cards que elevam com sombra dourada no hover
- Scroll animations discretas

**Animation:**
- Fade-in com translate-Y(20px) → 0 no scroll
- Cards: box-shadow dourada no hover (300ms ease-out)
- Navbar: background blur ao rolar

**Typography System:**
- Display: Playfair Display (clássico, premium)
- Body: Source Sans 3 (limpo, profissional)
- Numbers: Oswald (impactante)

## Abordagem 3: Tech Engineering Dark Gold ← ESCOLHIDA
<response>
<text>
**Design Movement:** High-Tech Industrial com Luxury Finish

**Core Principles:**
- Interface escura de alta tecnologia com acentos dourados estratégicos
- Tipografia geométrica e moderna para autoridade técnica
- Seções com profundidade usando gradientes sutis e texturas
- Elementos gráficos que remetem a circuitos e energia elétrica

**Color Philosophy:**
- Preto (#080808, #0F0F0F) como base dominante — poder, sofisticação
- Dourado/Âmbar (#D4900A, #F0B429, #FFD060) — energia, prestígio, condutividade
- Branco (#FFFFFF, #F5F5F5) — clareza, limpeza técnica
- Cinza (#1A1A1A, #252525, #333333) — profundidade e hierarquia

**Layout Paradigm:**
- Hero assimétrico: texto à esquerda (60%), imagem à direita com clip-path diagonal
- Seções com fundo alternado (escuro/escuro-médio) sem branco puro
- Cards com bordas sutis douradas e efeito de glow no hover
- Diferenciais em layout horizontal com ícones grandes

**Signature Elements:**
- Linha diagonal dourada como elemento decorativo entre seções
- Badge/tag dourado para destacar informações-chave
- Padrão de pontos/grid sutil no fundo do hero

**Interaction Philosophy:**
- Hover que "energiza" — elementos ganham brilho dourado
- Scroll reveal com stagger elegante
- Botão primário com gradiente dourado e sombra luminosa

**Animation:**
- Hero: fade-in + slide-up com 80ms stagger
- Cards: translateY(-4px) + golden box-shadow no hover (250ms ease-out)
- Navbar: backdrop-blur após 80px de scroll
- Floating WhatsApp: pulse animation suave

**Typography System:**
- Display: Barlow Condensed (bold 700/800 — técnico e impactante)
- Body: DM Sans (moderno, legível, profissional)
- Accent/Numbers: Barlow Condensed (600)
</text>

</response>
